Our project aims to improve the reliability of Automatic Weather Stations (AWS) by detecting abnormal sensor readings, identifying potential sensor faults, and supporting timely weather-related decisions.

The proposed system combines multi-sensor validation, spatial and temporal analysis, physics-informed anomaly detection, and predictive maintenance to improve weather data quality and reduce false alerts.

Our interactive prototype demonstrates four key modules:

Core AI & Sensor Fault Detection: Identifies abnormal weather readings and displays anomaly scores, severity levels, and possible causes.

Farmer Agro-Advisory: Demonstrates weather-based agricultural warnings and suggested actions.

Municipal & Waterlogging Monitoring: Displays potential waterlogging risks based on rainfall and drainage conditions.

Public Infrastructure Monitoring: Demonstrates weather-related safety alerts for infrastructure projects.

The current prototype is developed using HTML5, JavaScript, Tailwind CSS, and Chart.js. It features an interactive dashboard, simulated anomaly detection, sensor visualizations, and stakeholder-specific alerts.

Our goal is to develop a scalable platform that improves weather data reliability, supports disaster preparedness, reduces maintenance delays, and helps different stakeholders make informed decisions.
